MOHAMED YASSER — RED PORTFOLIO
================================

Files:
- index.html  : website structure, social links, and the 7 Google Drive videos
- style.css   : dark/black/red responsive design
- profile.jpg : the profile photo supplied in the chat

How to update the existing GitHub Pages website:
1. Open your existing repository:
   https://github.com/Mohamed8547g/mohamed-yasser-portfolio
2. Upload/replace these three files in the repository root:
   index.html, style.css, profile.jpg
3. If GitHub asks whether to replace existing files, confirm the replacement.
4. Commit the changes to the main branch.
5. Wait a few minutes, then refresh:
   https://mohamed8547g.github.io/mohamed-yasser-portfolio/

The website keeps the same GitHub Pages URL. Videos are embedded from Google Drive preview links.
If a video does not play inside the site, check that its Drive sharing is set to "Anyone with the link — Viewer".
