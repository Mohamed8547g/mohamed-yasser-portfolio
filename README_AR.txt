بورتفوليو Mohamed Yasser — أسود وأحمر
======================================

المحتويات:
- index.html: محتوى الموقع.
- style.css: التصميم والألوان والتجاوب مع الموبايل.
- script.js: القائمة والتفاعلات البسيطة.

معاينة الموقع:
افتح index.html في متصفحك. الخطوط تحتاج اتصالًا بالإنترنت، والموقع نفسه ثابت ولا يحتاج سيرفر.

قبل النشر:
1) استبدل إطار MY في قسم البداية بصورتك (راجع الملاحظة أدناه).
2) عدّل روابط إنستجرام وفيسبوك وتيك توك ويوتيوب في index.html.
3) غيّر your-email@example.com إلى بريدك الحقيقي.
4) استبدل بطاقات الأعمال التجريبية بروابط فيديوهاتك الحقيقية.
5) غيّر النصوص لو حبيت.

نشر مجاني على GitHub Pages:
1) أنشئ حسابًا على https://github.com إن لم يكن لديك حساب.
2) أنشئ Repository جديدًا، مثل: mohamed-yasser-portfolio
3) ارفع index.html وstyle.css وscript.js إلى جذر المستودع.
4) افتح Settings > Pages.
5) تحت Build and deployment اختر Deploy from a branch، ثم main و/(root)، واضغط Save.
6) بعد انتهاء النشر سيظهر رابط الموقع في صفحة Pages.

ملاحظات:
- GitHub Pages يستضيف المواقع الثابتة مجانًا.
- الموقع غير مفهرس تلقائيًا بالضرورة، لكنه ليس خاصًا أو محميًا بكلمة مرور؛ من معه الرابط يمكنه فتحه.
- إطار الصورة الحالي عنصر تصميم مؤقت وليس صورة شخصية حقيقية.
